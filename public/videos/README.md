# Video Assets Directory

Drop your high-resolution or web-optimized MP4 files directly into this directory:

- `showreel.mp4` — Main 2023–2026 Showreel video
- `project-01.mp4` — Project 01 Video / Commercial
- `project-02.mp4` — Project 02 Video / Docu-Series
- `project-03.mp4` — Project 03 Video / Fashion Campaign
- `project-04.mp4` — Project 04 Video / Brand Film

### External Video Support (YouTube / Vimeo)
You can also specify YouTube or Vimeo URLs directly in `src/data/projects.ts`. The player automatically detects the platform and renders an embedded cinema player.
